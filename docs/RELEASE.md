# Release

## One-time setup

1. **Developer ID Application** certificate in the keychain:

   ```sh
   security find-identity -v -p codesigning | grep "Developer ID"
   ```

2. Notarization credentials (your Apple ID and team ID):

   ```sh
   xcrun notarytool store-credentials "AC_PASSWORD" \
     --apple-id "you@example.com" --team-id XXXXXXXXXX --password "xxxx-xxxx-xxxx-xxxx"
   ```

## Build

```sh
DEVELOPMENT_TEAM=XXXXXXXXXX ./scripts/build-release.sh   # archive and Developer ID signing
./scripts/make-dmg.sh                                     # DMG with Applications shortcut -> dist/
./scripts/notarize.sh                                     # submit --wait -> staple -> spctl
```

Verify the result:

```sh
spctl -a -vvv -t install dist/PerfectWhisper-X.Y.Z.dmg
# expected: accepted, source=Notarized Developer ID
```

## Version

1. Bump `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` in `project.yml`.
2. Run `xcodegen generate`.
3. Add an entry to `CHANGELOG.md`.
4. Rebuild with the steps above.

## Publishing

The DMG is uploaded as a GitHub release asset; the source archive is generated by
GitHub from the tag.

The in-app updater reads GitHub Releases (`PWUpdateProject`,
`PWUpdateProvider = github`) and expects a tag like `v1.0.1` with a `.dmg` asset.

Keep commit and tag signing enabled:

```sh
git config --global tag.gpgsign true
```

## Pre-release checklist

- [ ] `spctl` reports `accepted`
- [ ] the app launches from the DMG after dragging to `/Applications`
- [ ] a model downloads on a clean system
- [ ] microphone and hotkey work after the first launch
- [ ] all three insertion modes work
- [ ] launch at login survives a reboot
- [ ] `CHANGELOG.md` is updated and the version matches the DMG name
